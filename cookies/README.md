# Cookies go here

Drop your Genspark session cookie files in this folder, named `cookies1.txt`,
`cookies2.txt`, ... (primary account first — it serves everything it can,
extras absorb parallel bursts).

The gateway auto-discovers `cookies/cookies*.txt` on start — no config needed.

**These files are secrets.** They are git-ignored and will never be committed.
Copy them yourself to any machine where you install this gateway (USB, Drive,
scp — never through the repo). Anyone who gets a cookie file can use that
Genspark account.

How to export: log in to genspark.ai in your browser, export cookies for the
domain as Netscape-format `cookies.txt`, save one file per account here.
